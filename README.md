# Credit Risk Analysis

A data analytics project that analyzes customer credit risk using **Python, SQL, and Power BI** to identify loan default patterns and support data-driven lending decisions.

---

##  Tech Stack

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL (MySQL)
- Power BI

# Project Workflow

**Data Cleaning (Python)** → **EDA (Python)** → **Business Analysis (SQL)** → **Interactive Dashboard (Power BI)**

---



## Key Insights

- Higher interest rates are associated with increased loan default risk.
- Lower loan grades have higher default rates.
- Employment length and income influence repayment behavior.
- Loan purpose impacts credit risk.
